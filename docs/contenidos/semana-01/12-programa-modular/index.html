Tu primer programa modular

Construí una aplicación de consola que reciba un nombre, genere un saludo y conserve un historial en un archivo.

OBJETIVOIntegrar sin copiar a ciegas

Terminal, argumentos, módulos, archivos, asincronismo y Git aparecen en un único recorrido.

Qué vas a integrar

01

Terminal

Crear la carpeta y ejecutar Node.js.

02

Entrada

Leer process.argv y validar un nombre.

03

Módulos

Separar saludo e historial.

04

Archivos

Guardar registros de forma asíncrona.

code .

app.js
console.log("Programa iniciado");

Checkpoint 3 · Dato de entrada

app.js
const nombre = process.argv[2] ?? "estudiante";
console.log(`Hola, ${nombre}`);

Checkpoint 4 · Extraé el saludo

saludos.js
function crearSaludo(nombre) {
  return `Hola, ${nombre}`;
}
module.exports = { crearSaludo };
app.js
const { crearSaludo } = require("./saludos");
const nombre = process.argv[2] ?? "estudiante";
console.log(crearSaludo(nombre));

Checkpoint 5 · Historial asíncrono

historial.js
const { appendFile } = require("node:fs");
function guardarSaludo(texto, callback) {
  appendFile("historial.txt", texto + "\n", "utf8", callback);
}
module.exports = { guardarSaludo };

Checkpoint 6 · Coordinación completa

app.js
const { crearSaludo } = require("./saludos");
const { guardarSaludo } = require("./historial");
const nombre = process.argv[2] ?? "estudiante";
const saludo = crearSaludo(nombre);
console.log(saludo);
guardarSaludo(saludo, (error) => {
  if (error) return console.error("No se pudo guardar");
  console.log("Historial actualizado");
});

Probalo como usuario

  1. Ejecutá sin argumento.
  2. Ejecutá con un nombre.
  3. Repetí con otro nombre.
  4. Abrí historial.txt.
  5. Provocá un error controlado y leé el mensaje.
