02.1 PREPARACIÓN DESDE CERO

Conocé la terminal integrada

Visual Studio Code será nuestro centro de trabajo. Dentro del editor escribiremos código y abriremos una terminal para ejecutar comandos.

PARA EMPEZAR No se espera experiencia previa.

Aprenderemos solamente el recorrido necesario para esta cursada, una instrucción por vez.

01 Primer contacto 02 Leer la terminal 03 Comandos 04 Errores 05 Práctica
01

ABRÍ TU ESPACIO DE TRABAJO

Tu primer contacto con la terminal

En Visual Studio Code elegí Terminal → New Terminal. Se abrirá un panel en la parte inferior. La terminal espera instrucciones escritas llamadas comandos. Escribí uno, presioná Enter y observá la respuesta antes de continuar.

02

UNA CONVERSACIÓN BREVE

Cómo leer una interacción

Primero la terminal muestra dónde estás, después escribís una instrucción y finalmente devuelve una respuesta. Solo escribís el comando: el prompt y la respuesta los muestra la computadora.

01

Prompt

Es la línea disponible para escribir. Suele incluir la carpeta actual y termina con un símbolo como >.

02

Comando

Es la instrucción que escribís después del prompt. No se ejecuta hasta que presionás Enter.

03

Respuesta

Puede ser información, una confirmación o un error. Cuando vuelve el prompt, la terminal está lista otra vez.

TERMINAL

PROMPTPS C:\Curso>

COMANDOecho Hola

RESPUESTAHola

NUEVO PROMPTPS C:\Curso>

03

UBICATE ANTES DE EJECUTAR

Seis comandos esenciales

Casi todos los comandos actúan sobre la carpeta actual. Comenzá con pwd, mirá el contenido con ls y recién después movete o creá una carpeta. Esta costumbre evita trabajar accidentalmente en otro lugar.

COMANDOPARA QUÉ SIRVEPROBALO
pwd

Muestra en qué carpeta estás.

Confirmá tu ubicación.
ls

Lista archivos y carpetas del lugar actual.

Buscá una carpeta conocida.
cd nombre

Entra en una carpeta.

Entrá en Documentos.
cd ..

Vuelve a la carpeta anterior.

Regresá un nivel.
mkdir semana-1

Crea una carpeta nueva.

Creá la carpeta del trabajo.
clear

Limpia la pantalla sin borrar archivos.

Ordená la vista.
PRIMER RECORRIDO GUIADO Una línea por vez

Esperá a que reaparezca el prompt antes de continuar.

pwd
mkdir semana-1
cd semana-1
code .

La última instrucción abre la carpeta actual en Visual Studio Code. Si ya está abierta, podés omitirla.

04

LEÉ LA EVIDENCIA

Si algo no sale como esperabas

Un mensaje de error no rompe la computadora. Leelo, revisá el comando y comprobá la carpeta actual antes de volver a intentarlo.

Path not found

La carpeta no existe

Ejecutá ls y copiá el nombre correcto.

not recognized

El comando no se reconoce

Revisá espacios y letras. Si acabás de instalar algo, reiniciá VS Code.

code .

El acceso directo no está disponible

Usá Archivo → Abrir carpeta y continuá.

REGLA ÚTIL

Mensaje → ubicación → escritura. Leé qué ocurrió, ejecutá pwd y ls, y después corregí una sola cosa.

05

MINI PRÁCTICA

Comprobá lo aprendido
