08 · INVESTIGACIÓN

Errores que probablemente vas a encontrar

Un error útil indica qué archivo, línea o etapa investigar. Leelo antes de modificar el código.

RUTINAObservar antes de adivinar

Reproducí, leé, ubicá, formulá una hipótesis, cambiá una sola cosa y volvé a comprobar.

Una rutina de seis pasos

  1. Reproducir
  2. Leer el mensaje completo
  3. Ubicar archivo y línea
  4. Traducir el mensaje
  5. Cambiar una cosa
  6. Volver a ejecutar

Mensajes frecuentes

MODULE_NOT_FOUND

No encuentra un módulo

Revisá ubicación, ruta, nombre y extensión.

ReferenceError

Nombre inexistente

Buscá errores de escritura o alcance.

TypeError

Valor inesperado

Observá qué dato recibió la operación.

ENOENT

Archivo inexistente

Comprobá cwd, ruta y nombre.

SyntaxError

Código incompleto

Revisá llaves, comillas y paréntesis.

await inválido

Contexto incorrecto

await necesita una función async o un módulo compatible.

MODULE_NOT_FOUND

Ejemplo
const { sumar } = require("operaciones");
// Falta ./ si operaciones.js es un archivo vecino.

Observá el recorrido

Mensajes temporales
console.log("1 · inicio");
console.log("2 · dato recibido:", nombre);
console.log("3 · antes de guardar");

Reaccioná con try/catch

Lectura controlada
try {
  const datos = JSON.parse(texto);
  console.log(datos);
} catch (error) {
  console.error("El contenido no es JSON válido");
}

Una bitácora breve

REGISTRÁ

Comando, mensaje completo, archivo, línea, hipótesis y cambio realizado.

EVITÁ

“No funciona”, capturas recortadas y varios cambios simultáneos.

COMPROBACIÓN

Puedo investigar sin adivinar
