05 · EVENT LOOP Y ASINCRONISMO

Una fila, muchas tareas en movimiento

JavaScript ejecuta una tarea por vez, pero Node.js puede delegar esperas y continuar con el trabajo que ya está listo.

IDEA CENTRALJavaScript no hace dos cosas a la vez

Evita quedarse esperando sin necesidad; el event loop coordina el regreso de las tareas listas.

Cuatro piezas

01

Pila de ejecución

Ejecuta la tarea actual.

02

APIs de Node.js

Administran esperas de archivos, red o timers.

03

Cola de tareas

Conserva callbacks listos.

04

Event loop

Permite ingresar la próxima tarea cuando la pila queda libre.

Predicción A, B y C

orden.js
console.log("A");
setTimeout(() => console.log("B"), 0);
console.log("C");

Leer sin detener el programa

leer-archivo.js
const { readFile } = require("node:fs");
console.log("Inicio");
readFile("datos.txt", "utf8", (error, contenido) => {
  if (error) return console.error("No se pudo leer");
  console.log("Archivo listo:", contenido);
});
console.log("Fin");
BLOQUEANTE

readFileSync ocupa la pila hasta terminar.

ASÍNCRONO

readFile delega y avisa mediante callback.

PISTA OPCIONALPromesas antes que temporizadores

Cuando la pila queda libre, las microtareas de promesas tienen prioridad sobre los temporizadores.
