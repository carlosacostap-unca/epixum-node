¿Qué lugar ocupa el back end?

El back end recibe solicitudes, aplica reglas, trabaja con datos y devuelve respuestas.

DEFINICIÓN PARA RECORDARLa interfaz pide; el back end decide

Las reglas confiables, los permisos, el stock y los precios se vuelven a comprobar en el servidor.

Las partes de una aplicación

01

Front end

Muestra información y recibe acciones.

02

Back end

Valida, aplica reglas y coordina operaciones.

03

Base de datos

Conserva información organizada.

04

Servicios externos

Resuelven pagos, correo, mapas u otras capacidades.

Reservar un libro, de punta a punta

  1. Recibir la solicitud
  2. Validar usuario y datos
  3. Consultar disponibilidad
  4. Aplicar la regla
  5. Registrar la reserva
  6. Responder el resultado
