Seis ideas que deberían quedar

  1. Node.js ejecuta JavaScript fuera del navegador.
  2. El runtime define qué APIs existen.
  3. El event loop coordina tareas listas.
  4. Los módulos separan responsabilidades.
  5. Los errores aportan evidencia.
  6. Git y GitHub cumplen papeles distintos.

Conceptos que no conviene mezclar

LENGUAJE / RUNTIME

JavaScript es el lenguaje; Node.js es el entorno.

GIT / GITHUB

Git registra localmente; GitHub aloja el remoto.

MÓDULO / PAQUETE

Un módulo organiza código; un paquete se distribuye como proyecto reutilizable.

ERROR / CAUSA

El mensaje describe un síntoma; la investigación identifica la causa.

Glosario

Runtime

Entorno que ejecuta código y ofrece APIs.

Callback

Función que se ejecuta cuando una operación informa su resultado.

Commit

Versión guardada del proyecto.

Repositorio

Proyecto cuya historia registra Git.

Remoto

Repositorio conectado, normalmente alojado en GitHub.

CommonJS

Sistema de módulos basado en require y module.exports.
